# TechDocs 기획 의도

## 프로젝트 배경과 목적

TechDocs는 키워드로 특허를 검색하는 기존 TechLens 프로젝트에서 출발했습니다. 더존ICT그룹 키컴의 공공 API 활용 솔루션 개발 프로젝트로 시작했으며, 초기에는 특허 통계를 대시보드로 보여주는 플랫폼을 구현했습니다.

그러나 키워드 검색만으로는 사용자의 아이디어와 의미가 유사한 특허를 충분히 찾기 어렵다는 한계가 있었습니다. 이를 개선하기 위해 AI Agent와 RAG를 활용하여 자연어로 관련 특허를 검색하고, 사용자의 아이디어 또는 제품이 기존 특허의 청구항과 얼마나 유사한지 분석하는 솔루션으로 발전시키고자 합니다.

자체 R&D 조직이나 특허 전문 인력이 부족한 중소·중견기업이 다음 업무를 수행할 수 있도록 지원하는 것이 목적입니다.

- 경쟁사의 특허를 바탕으로 기술 개발과 투자 흐름을 파악합니다.
- 새로운 아이디어와 유사한 선행 특허가 존재하는지 미리 확인합니다.
- 제품이나 기술이 기존 특허의 청구항과 충돌할 가능성을 사전에 검토합니다.

TechDocs의 분석 결과는 특허 침해 여부를 확정하는 법률 판단이 아니라, 전문가 검토 전에 참고할 수 있는 근거와 비교 결과를 제공하는 것을 목표로 합니다.

## 주요 사용자

- 사내 연구개발 담당자
- 새로운 사업을 준비하는 스타트업 대표
- 자체 R&D 조직이나 특허 전문 인력이 부족한 중소·중견기업

## 해결하려는 문제

- 사용자의 아이디어와 유사한 특허가 이미 존재하는지 키워드가 아닌 자연어로 확인하기 어렵습니다.
- 기존 특허의 청구항을 수작업으로 분해하고 제품 또는 아이디어와 비교하려면 많은 시간과 전문 지식이 필요합니다.
- 보유한 특허 데이터가 부족하면 검색 결과의 범위와 품질이 제한됩니다.
- AI가 제시한 결과에 근거 특허와 청구항별 비교 내용이 없으면 사용자가 결과를 신뢰하고 검토하기 어렵습니다.

## 핵심 기능과 사용 흐름

### 1. 자연어 기반 유사 특허 검색

1. 사용자가 아이디어나 찾고 싶은 기술을 자연어로 입력합니다.
2. AI Agent가 질의를 분석하고 RAG를 통해 의미가 유사한 특허를 검색합니다.
3. 내부 데이터가 부족하면 KIPRIS API에서 관련 특허를 수집합니다.
4. 수집한 데이터를 검색에 반영하고 결과를 다시 보강합니다.
5. 검색 근거와 관련 특허를 사용자에게 제공합니다.

### 2. 청구항 비교 분석

1. 사용자가 검토할 아이디어 또는 제품 설명을 입력합니다.
2. 관련성이 높은 특허와 청구항을 찾습니다.
3. AI가 청구항을 구성요소 단위로 나눕니다.
4. 사용자의 아이디어와 각 구성요소를 비교합니다.
5. 일치하거나 부족한 부분과 함께 침해 가능성 검토에 필요한 근거를 제공합니다.

검색, 데이터 수집, 재검색 및 분석 과정은 여러 Agent가 역할을 나누고, 데이터가 부족한 경우 스스로 보강하는 흐름으로 구성합니다.

## 리팩토링 방향

이번 리팩토링의 목표는 작성자가 전체 코드 흐름을 이해하고 직접 유지보수할 수 있는 구조를 만드는 것입니다.

- 전체 코드를 검토하여 실제 동작과 맞지 않거나 불필요한 주석을 정리합니다.
- 복잡한 로직에는 동작 설명이 아니라 해당 구현이 필요한 이유를 한국어로 기록합니다.
- 계층별 책임이 섞인 부분을 찾아 명확하게 분리합니다.
- 자연어 검색, 데이터 보강 및 청구항 분석의 흐름이 코드 구조에서 드러나도록 정리합니다.
- 기존 기능과 외부 API 계약을 유지하면서 작은 단위로 검증하고 개선합니다.
