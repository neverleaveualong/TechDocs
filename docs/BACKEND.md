# AI Agent 백엔드 기술 문서

- 수정일자: 2026-07-30 13:49 KST
- 작성자: Woohyun Sim
- 목적: 자연어 검색, 자동 수집, 답변 생성, ClaimLens 분석의 백엔드 책임과 흐름을 설명합니다.

## 역할

- 자연어 질문을 특허 검색 요청으로 처리합니다.
- 검색 결과가 부족하면 외부 특허 데이터를 수집하고 다시 검색합니다.
- 검색 근거와 출처를 바탕으로 AI 답변을 생성합니다.
- 제품 설명과 특허 청구항을 구성요소 단위로 비교합니다.
- 검색 및 분석 과정의 진행 상태를 프론트엔드에 실시간으로 전달합니다.
- 검색 기록, 사용자 피드백, ClaimLens 분석 결과를 저장합니다.

## 자연어 검색 흐름

- 사용자가 자연어로 특허 검색 질문을 입력합니다.
- 검색 계획을 만들고 관련 특허 후보를 조회합니다.
- 검색 결과의 관련성과 수량을 확인합니다.
- 결과가 부족하면 필요한 외부 특허 정보를 수집합니다.
- 수집한 정보를 검색 대상에 반영한 뒤 다시 검색합니다.
- 충분한 근거가 확보되면 출처와 함께 답변을 생성합니다.
- 검색 기록은 Repository를 통해 저장하며 기록 저장 실패가 검색 응답을 중단시키지 않도록 처리합니다.

## AI Agent 책임

- Supervisor:
  - 현재 검색 상태를 확인하고 다음 작업을 결정합니다.
- Retriever:
  - 특허 후보를 검색하고 결과 품질을 평가합니다.
- Ingest:
  - 외부 특허 정보를 수집하고 검색 가능한 형태로 저장합니다.
- Generator:
  - 검색 근거를 바탕으로 답변을 생성합니다.
- ClaimLens:
  - 제품 기능과 청구항 구성요소를 비교하고 분석 보고서를 만듭니다.

## 계층별 책임

- API:
  - 요청 파라미터 검증, 응답 형식, HTTP 오류와 스트리밍 응답을 담당합니다.
- Service:
  - 검색 스트림과 ClaimLens 분석의 전체 업무 흐름을 조정합니다.
- Agent:
  - 검색, 수집, 답변 생성과 같은 AI 작업 단위를 수행합니다.
- Repository:
  - QueryLog 등 데이터 저장과 조회를 담당합니다.
- Core:
  - 검색, 임베딩, 재정렬, 답변 생성과 같은 도메인 로직을 담당합니다.
- Model:
  - API 요청·응답과 데이터베이스 모델을 정의합니다.

## 스트리밍 방식

- RAG 검색:
  - `application/x-ndjson` 형식으로 에이전트 이벤트와 답변 조각을 전달합니다.
- ClaimLens 분석:
  - `text/event-stream` 형식으로 분석 단계를 전달합니다.
- 스트리밍 오류:
  - 서버 로그에는 원인을 남기고 클라이언트에는 처리 가능한 오류 메시지를 전달합니다.
  - 검색 기록 저장 실패만으로 전체 검색 응답을 실패시키지 않습니다.

## 주요 외부 연동

- KIPRIS:
  - 특허 검색과 자동 수집에 사용합니다.
- Pinecone:
  - 특허 검색 데이터와 임베딩을 저장합니다.
- PostgreSQL:
  - 검색 기록, 피드백, ClaimLens 결과와 자동 수집 상태를 저장합니다.
- OpenAI:
  - 자연어 답변 생성과 문서 임베딩에 사용합니다.

## 유지보수 원칙

- API 계층에 핵심 비즈니스 판단과 데이터베이스 직접 접근을 추가하지 않습니다.
- 여러 저장소를 조합하거나 상태 변경 조건을 판단하는 로직은 Service에 둡니다.
- 데이터 저장 방식은 Repository에 감추고 API나 Agent가 데이터베이스 세부 구현에 의존하지 않도록 합니다.
- API 응답과 DB 스키마를 변경할 때 프론트엔드 타입과 문서를 함께 검토합니다.
